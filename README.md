# FRIDAY AI Assistant 2.0 — starter website

A responsive static website starter for the FRIDAY assistant project.

## Run locally
Open `index.html` in a modern browser. Microphone input generally requires HTTPS or localhost and browser permission.

## Deploy to Render
1. Upload all files in this folder to your GitHub repository (keep `index.html`, `style.css`, and `app.js` at the repository root).
2. In Render, choose **New + → Static Site**.
3. Connect the `friday-ai-assistant` GitHub repository.
4. Build command: leave blank.
5. Publish directory: `.`
6. Click **Create Static Site**.

## Important security note
This is a front-end demo. It has no real login, account system, secure access control, or live AI API connection. Do not put passwords, API keys, or private information in these files. Real authentication and AI integration must be implemented on a server with secrets stored as environment variables.
